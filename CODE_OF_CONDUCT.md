# Code of Conduct

## Our pledge

We want participation in this project to be a respectful, harassment-free
experience for everyone, regardless of age, body size, disability, ethnicity,
sex characteristics, gender identity and expression, experience level,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Assume good intent; critique ideas, not people.
- Accept feedback gracefully and give actionable feedback.
- Respect privacy: do not publish credentials, provider URLs, `.env` contents,
  `auth.json`, or personal data.
- Do not use the project to harass, spam, or distribute malware.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, doxxing, sexualized
attention, deliberate intimidation, and publishing others' private information
without permission are not acceptable.

## Scope

This applies in project repositories, issues, pull requests, discussions, and
other spaces where someone represents the project.

## Enforcement

Report conduct issues privately through GitHub (for example, a private message
to the maintainer or a GitHub security advisory if the report is sensitive).
Reports will be reviewed in good faith; maintainers may remove content, close
threads, or block participants when needed. Retaliation against reporters is
not acceptable.
