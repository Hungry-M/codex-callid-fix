## 结论

- 2026-11-11 在原 provider 恢复额度后，成功复现了原始
  `function_call_output.call_id` 错误；

## 原始问题复现

环境：

```text
Windows 10 19045
Codex Desktop / 原 provider（额度恢复后）
修复代理：ON
```

观察：

- 未开启修复代理解析时，出现原始 `call_id` 相关错误；
- 开启修复代理后，同一请求成功；
- 没有记录 provider URL、账号或 API key。

边界：

- 这是一次真实复现，不代表所有 Codex 版本/provider 都相同；
- 仍应以 `backend/server.log` 的 `rewrote=` 和实际请求为准；
- 没有保存完整请求体或认证信息。

修改：

- 设置说明使用显式换行；
- `wraplength` 从 500 调整为 560；
- 设置对话框从 `620x420` 调整为 `640x430`；
- 说明标签左对齐。

本机布局测量：

```text

note: 显式两行，第二行从“切换语言”开始
```

截图来自另一台 Win11 设备时出现过外观选择器覆盖/换行异常；本次修复针对结构布局，不依赖该设备本机复现。
